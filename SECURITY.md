# Security

This repository holds no server, no secret and no real data, but it defines what an AI is allowed to display in Bazous (`src/canvas`, `schema/canvas.json`). Any way around that list (script injection, a network request from the iframe, a leak through an intent) is a vulnerability.

Report it privately to **contact@bazous.com** (subject: "security") rather than in a public issue. We acknowledge within 72 hours and publish a fix and an advisory once the problem is solved.
